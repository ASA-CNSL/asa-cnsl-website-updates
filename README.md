# ASA Statistical Consulting Section Website Update Tracker
This repository is used to track updates to the ASA CNSL website.

## Submitting an Issue/Change Request
To submit a change request, navigate to the 'Issues' tab on the top bar, then click the green button labeled 'New Issue'.

## Utility Package
The included `asa-cnsl-utils` package can be used to perform some website update functionality. 

### Officer Table Updates
Updates to the current and historical officer tables should be made in the `.md` files located at `src/asa-cnsl-utils/resources/officers`. 

You can then run the `generate_officer_html()` function to generate new styled HTML tables for the website.
